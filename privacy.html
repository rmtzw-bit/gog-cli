プライバシーポリシー

最終更新日: 2026年9月23日

概要

gog CLI（以下「本ツール」）は、開発者本人が自身の Google アカウントのデータをコマンドラインから操作するために使用する個人用ツールです。第三者にサービスとして提供するものではありません。

取得する情報

本ツールは、利用者が Google の OAuth 同意画面で明示的に許可した範囲で、Gmail、Google カレンダー、Google Drive、Google ドキュメント、Google スプレッドシート、Google コンタクトのデータにアクセスします。

情報の保存場所と利用目的

取得したデータおよび認証トークンは、本ツールを実行している利用者自身のコンピュータ上にのみ保存されます。開発者や第三者が運営するサーバーに送信、保存、共有されることはありません。データは利用者がコマンドで指示した操作を実行する目的にのみ使用します。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

アクセスの取り消し

利用者は、Google アカウントのセキュリティ設定からいつでも本ツールのアクセス権を取り消すことができます。また、ローカルに保存された認証トークンは本ツールのコマンドで削除できます。

お問い合わせ

本ポリシーに関するお問い合わせは、Google OAuth 同意画面に記載のサポートメールアドレスまでご連絡ください。
